This project predicts employee performance ratings using a dataset with demographic, job, and performance metrics. It aims to identify factors influencing performance and build accurate predictive models.

The project uses the dataset to predict employee performance ratings, employing data preprocessing, feature engineering, and machine learning models to achieve accurate predictions.

1. Employee Environment Satisfaction: Maximum employees with performance rating belong to levels 3 & 4 (367 & 361). 2. Employee last salary hike percent: Salary hike 11-19% gets 2 & 3 ratings most. 20-22% gets 4. 3. Employee work life balance: Level 3 shows high performance rating.
