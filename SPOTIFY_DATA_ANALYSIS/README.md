## SPOTIFY_DATA_ANALYSIS
Import Libraries, EDA, Data Preprocessing, Feature Engineering, Model Building, Model Evaluation

The data has no null values. Feature engineering included scaling and encoding.

This project predicts track popularity on Spotify using various audio features. The dataset includes features like danceability, energy, loudness, etc.

R2 score of 0.3902. XGBoost was used.
